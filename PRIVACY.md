# Privacy

TeamBrain stores events on the local filesystem chosen by the user. The dashboard loads its assets locally, collects no telemetry, and invokes no AI provider. Explicit CLI Git pull/push commands contact the configured remote and share committed repository content, not just selected events.

Automatic synchronization is opt-in. The dashboard runs a periodic worker while it is open; an explicitly installed post-commit hook and managed agent session command can also request a one-shot sync without the dashboard. Synchronization pulls the selected memory repository, stages only `shared/` and `teams/`, commits those changes, and pushes them to the configured remote. The `teams/` scope includes full TeamBrain team/project chat messages, notes/events, tasks, calendar records, project metadata, member caches, extracted Markdown document imports, commit records, and privacy-reviewed agent outcome summaries. TeamBrain does not silently read external terminal, Codex, Claude, editor, or AvenoxBeyin conversations. The commit hook captures commit metadata, changed paths, and file statistics, but not patch bodies. Agent session finish receives only the concise summary and sources that the agent is explicitly instructed to submit; raw transcripts are not an input.

The `publish` command requires `--privacy-reviewed true` and creates a pending receipt only. Users must remove personal notes, secrets, credentials, customer data, and raw conversation content before review. AvenoxBeyin data is never read implicitly; imports must be explicitly exported and selected. During first-time interactive setup, an optional initial contribution reads only a JSON file chosen by the user, requires one exact project ID, ignores raw body/chat fields, previews only that project's reviewed summaries and source references, and asks separately for privacy and sharing consent before creating a pending receipt.

Future AI and relay integrations must be disabled by default, declare every data transfer, and preserve a fully local mode. Do not place secrets, credentials, or unredacted customer data in memory events.

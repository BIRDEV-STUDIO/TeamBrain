# Contributing

Thank you for helping TeamBrain remain local-first and interoperable.

1. Open an issue or discussion for protocol/schema changes before implementing them.
2. Keep canonical document changes backward-compatible or version `schema_version`.
3. Add focused tests for every behavior change and run `npm test`.
4. Do not add telemetry, automatic network calls, or AI-provider calls without explicit opt-in and privacy documentation.

Use small, reviewable pull requests. The canonical event format is a public compatibility contract.
